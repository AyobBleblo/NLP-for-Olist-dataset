UNIT 02

Full-Stack E-Commerce & Recommender Architecture

Technology Stack & Design

  • Frontend Framework: Modular Vanilla ES6+ JavaScript with CSS custom properties (design system) and semantic HTML5 — zero heavy bundler overhead.
  • Backend Architecture: Built with Django 6.1 and Django REST Framework (DRF) exposing 11 read-optimized REST endpoints.
  • Offline Batch Pipeline: All heavy ML models (NLLB-200 translation, DistilBERT sentiment, SVD & CBF recommendation matrices) are precomputed into database tables.
Architecture Highlight: Performance
“Zero ML inference inside the web request path”
Guaranteed Response Time: < 50 ms
*Heavy model scoring runs in offline batch jobs, avoiding GPU server bottlenecks.

Key Architectural Decision
Decoupled Asynchronous Intelligence:
Real-time user actions (cart additions, checkout) update transactional tables instantly. The recommendation engine reads precomputed latent vectors and hybrid scores, enabling high-concurrency e-commerce scale without request-time ML latency.
